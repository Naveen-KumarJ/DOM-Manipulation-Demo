# DOM Manipulation Example

This repository demonstrates the use of basic DOM manipulation techniques with HTML and JavaScript. It includes a simple example of how to dynamically style and modify an HTML element using JavaScript.

## Project Overview

The project consists of the following files:

1. **index.html**:
   - Provides the structure of the webpage.
   - Contains a `<div>` element with an ID of `box` that serves as the target for DOM manipulation.

2. **index.js**:
   - Contains JavaScript code to manipulate the DOM.
   - Dynamically applies styles such as background color, font size, padding, margin, and more to the target `<div>` element.

### Key Features:
- Changes the background color of the target `<div>`.
- Adjusts font size, weight, and color.
- Sets the dimensions (height and width) of the element.
- Adds padding and margin for layout customization.

## How to Run the Project Locally

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/your-username/DOM-Manipulation-Example.git
   ```

2. Navigate to the project directory:
   ```bash
   cd DOM-Manipulation-Example
   ```

3. Open the `index.html` file in any modern web browser.
